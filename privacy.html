개인정보 처리방침

맘스북스(이하 “서비스”)는 개인이 비영리로 운영하는 무료 독서기록 서비스입니다. 본 방침은 서비스가 어떤 정보를 어떻게 다루는지 설명합니다.

1. 수집하는 정보

가. 기기 내 저장(로그인 없이 사용 시)

  • 내가 추가한 책, 폴더, 별점·한줄평, 읽기 상태
  • 프로필(닉네임, 학년, 지역, 아바타), 화면·공개 범위 설정

이 정보는 사용자의 브라우저(localStorage)에만 저장되며, 로그인하지 않으면 서버로 전송되지 않습니다.

나. 로그인 시(선택)

  • 카카오 또는 구글 계정으로 로그인할 때 제공되는 이메일과 고유 식별자
  • 카카오 닉네임·프로필 이미지(닉네임은 서비스 내에서 변경 가능)

로그인 시 위 정보와 서재·프로필 데이터가 동기화를 위해 서버(Supabase)에 저장될 수 있습니다.

2. 이용 목적

  • 독서 기록의 저장·표시 및 여러 기기 간 동기화(로그인 시)
  • 책 검색·추천·통계 제공
  • 공개 범위를 ‘공개’로 설정한 경우의 랭킹·서재 공유

3. 외부 서비스·제3자 제공

서비스 제공을 위해 아래 외부 서비스를 이용합니다. 책 검색·도서관 조회 시 도서명·ISBN 등 요청에 필요한 정보가 해당 서비스로 전송됩니다.

  • Supabase — 로그인 인증 및 데이터 저장
  • Kakao — 카카오 로그인, 도서 검색 API
  • 알라딘(Aladin) — 도서 정보 조회(Cloudflare Worker 경유)
  • 도서관정보나루 — 가까운 도서관 소장·대출 정보 조회

서비스는 개인정보를 위 목적 외로 판매하거나 광고 목적으로 제3자에게 제공하지 않습니다.

4. 보관 및 파기

  • 기기 내 데이터: 사용자가 설정 화면의 ‘이 기기에서 데이터 삭제’로 언제든 삭제할 수 있습니다.
  • 로그인 계정 데이터: 회원 탈퇴 시 계정과 연결된 데이터를 삭제합니다.

5. 이용자의 권리

  • 프로필 편집을 통한 정보 열람·수정
  • 설정 화면에서 기기 데이터 삭제
  • 로그인 사용자의 회원 탈퇴(계정 및 연결 데이터 삭제)
