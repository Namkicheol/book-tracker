# 추가 출시 점검 — 2026-11-06

공유·프로필 외의 실제 실패 경로와 주요 화면을 점검했다. 유료화·네이티브 패키징은 변경하지 않았다.

## 재현 후 수정

- 추천 일괄 담기: 저장소가 실패를 반환하면 성공 건수에 포함하지 않고 실패 항목의 선택을 유지한다. 재시도는 남은 책만 저장한다.
- 검색: 진행 중인 조회를 잘못된 ISBN이나 빈 제목 검색으로 대체했을 때 로딩 표시를 해제한다. 이전 조회 결과는 계속 무시한다.
- 기기 데이터 삭제: 브라우저 저장소가 삭제를 거부하면 실패를 알리고 현재 화면과 데이터를 유지한다.
- 폴더: 삭제 표시 저장 실패 시 책의 원래 폴더 연결 복원을 시도한다. 복원도 거부되는 경우 원자적 복구를 보장하지 않으며 실패 상태를 유지하고 서버 삭제를 보내지 않는다. 서재의 폴더 생성·삭제 버튼도 실패를 확인한 뒤 오류를 알리고 선택을 보존한다.
- 배지: 계산 근거가 없는 4개를 제외하고 실제 획득 가능한 8개만 표시한다. 완독 배지에 읽을 예정·읽는 중 책을 포함하지 않는다. 배지를 키보드로 누를 수 있는 버튼으로 바꾸고 획득 여부와 안내를 읽을 수 있도록 했다.
- 서재 검색에 접근 가능한 이름을 추가하고, 폴더에서 Delete 키를 누르면 기존 삭제 확인을 거치도록 했다.

## 검증

- HTML의 로컬 링크·자산 및 manifest 아이콘에 누락 없음.
- 격리 WebKit 320/390px × 주요 7개 화면: 가로 넘침·페이지 JavaScript 오류 없음. 상세는 없는 책 ID의 복구 안내를 확인했다.
- 실제 DOM에서 추천 부분 저장 실패→재시도, 잘못된 대체 검색→지연 결과 무시, 기기 삭제 실패, 폴더 저장 실패·분류 복원 및 선택 유지 확인. 실제 회원 데이터 없이 합성 fixture 사용.
- 자동 테스트 227개 통과. 배지 8개·완독 2권/읽을 책 10권에서 완독 10권 배지 미획득·Enter 조작·상태 안내와 폴더 실패 안내를 실제 DOM에서 확인했다. 배포의 최종 결과는 PR 및 Obsidian 운영 기록에서 확인한다.

## 남은 일과 범위

- 실제 iPhone 공유 시트·홈 화면 실행, 실제 계정의 기기 간 동기화·일반 Google 로그인·폐기용 계정 탈퇴는 별도 검증이 필요하다.
- 앱스토어·플레이스토어 패키징과 제출은 미완료다.
- 오프라인에서는 이미 캐시한 화면만 재사용 가능하다. 처음 방문하는 화면은 연결 안내가 나온다. 완전한 오프라인 앱으로 소개하지 않는다.
- 현재 UI에서 호출하지 않는 `Storage.importData`의 저장 실패 처리는 백업 가져오기 UI를 제공하기 전에 보강해야 한다.
