# 출시 준비 기록 — 공유 카드·공개 설정, 2026-11-06

## 이번 변경

- 공유 카드에 5개 레이아웃(우리 집 책장, 이번 달 기록, 독서 정원, 표지 모아보기, 독서 발자국)과 기존 5개 배경을 조합할 수 있게 했다.
- 표지 모아보기는 서재에서 최근 책 최대 6권을 보여 주고, 독서 발자국은 완독 도서 수와 다음 목표까지 남은 권수를 표시한다. 서재 수와 완독 수를 구분하고, 프로필 문구도 읽은 책으로 오해되지 않도록 바꿨다.
- 긴 닉네임은 카드 폭에 맞춰 글자 크기를 줄이고 필요하면 말줄임한다.
- Canvas 2D context가 없는 경우 내보내기를 실패 처리하고, 최초 카드 생성 오류를 안내한 뒤 다시 시도할 수 있게 버튼을 복구한다. 초기 생성 중 중복 클릭도 막는다.
- 공개 설정 화면에서 사용자가 공개 범위를 바꾼 뒤 늦게 도착한 서버 조회 결과나 오류가 선택값·안내를 덮어쓰지 않도록 했다.

## 추가 출시 점검 — 프로필 편집과 공유 중 계정 전환

- 프로필 아바타·닉네임을 키보드로 실행할 수 있는 버튼으로 바꾸고, 모바일 430px 이하에서는 이미지 공유 버튼을 별도 줄에 배치했다. 초기 HTML의 예시 독서 목표·배지 수를 제거했다.
- 프로필 편집에서 아바타를 선택하고 저장할 수 있다. 기존 사진 유지, 취소 시 변경 없음, Escape 닫기·초점 복귀를 지원한다.
- 계정 전환·로그아웃 시 이전 프로필 편집창과 공유창을 닫고 이미지 URL을 해제한다. 이미지 생성 중 계정이 바뀌거나 다른 계정을 거쳐 돌아와도 이전 카드가 뒤늦게 열리거나 저장되지 않도록 했다.
- 책 상세에서 저장·공유 중 스타일 변경을 차단해 새 스타일을 선택했는데 이전 이미지가 저장되는 경합을 수정했다.
- 자동 테스트 211개 통과. 격리 WebKit에서 프로필 선택 취소·저장·새로고침 유지, Enter/Escape·초점 복귀, 320/390/430px 넘침 없음, 선택한 아바타의 카드 반영을 확인했다. 실제 계정 변경 없이 로컬 fixture로 검증했다.
- WebKit 실제 DOM에서 합성 계정 A→B 전환 시 미리보기 종료·URL 해제·이전 버튼 내보내기 0회, 이미지 인코딩 중 A→B→A 전환 시 늦은 미리보기 차단을 확인했다. 상세 카드의 지연 저장·모의 네이티브 공유 중 스타일 잠금과 완료 후 실제 스타일 렌더링도 확인했다. 페이지 오류 0.
- 추가 변경의 배포 증빙은 PR 및 Obsidian 운영 기록에 남긴다. 위 실제 기기·로그인·스토어 관련 남은 항목은 유지한다.
