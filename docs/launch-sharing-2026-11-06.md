# 출시 준비 기록 — 공유 카드·공개 설정, 2026-11-06

## 이번 변경

- 공유 카드에 5개 레이아웃(우리 집 책장, 이번 달 기록, 독서 정원, 표지 모아보기, 독서 발자국)과 기존 5개 배경을 조합할 수 있게 했다.
- 표지 모아보기는 서재에서 최근 책 최대 6권을 보여 주고, 독서 발자국은 완독 도서 수와 다음 목표까지 남은 권수를 표시한다. 서재 수와 완독 수를 구분하고, 프로필 문구도 읽은 책으로 오해되지 않도록 바꿨다.
- 긴 닉네임은 카드 폭에 맞춰 글자 크기를 줄이고 필요하면 말줄임한다.
- Canvas 2D context가 없는 경우 내보내기를 실패 처리하고, 최초 카드 생성 오류를 안내한 뒤 다시 시도할 수 있게 버튼을 복구한다. 초기 생성 중 중복 클릭도 막는다.
- 공개 설정 화면에서 사용자가 공개 범위를 바꾼 뒤 늦게 도착한 서버 조회 결과나 오류가 선택값·안내를 덮어쓰지 않도록 했다.

## 검증 상태

- 자동화 전체 테스트: 194개 통과(현재 작업 세션 확인).
- 격리 모바일 WebKit: 320/390/430px에서 5종 카드 모두 1080×1350, 가로 넘침 없음. 빈 서재·혼합 독서 상태·긴 별명·이미지 실패·빠른 선택 전환, PNG 다운로드를 확인했다. 실제 계정 쓰기 없음.
- Aside: 비로그인 프로필에서 공유창의 5개 구도·5개 배경·저장/공유 버튼을 확인했다. 초기 locator 대기는 실패했으나 새 snapshot에서 정상 렌더와 페이지 오류 0을 확인했다.
- 육안 검수에서 책장 배경과 겹치는 완독 목표 문구를 발견해 밝은 패널로 보강했다.
- 프로덕션 배포: 미실행.

## 출시 전 남은 확인

- 실제 iPhone에서 네이티브 공유 시트와 이미지 저장 확인.
- 실제 여러 기기에서 계정 전환 및 서재 동기화 확인.
- Google 로그인 일반 사용자 공개 설정 및 OAuth 왕복 확인.
- 별도 폐기 가능한 테스트 계정으로 계정 삭제와 재조회 확인.
- 네이티브 앱 패키징과 앱스토어·플레이스토어 제출은 별도 미완료 항목.
