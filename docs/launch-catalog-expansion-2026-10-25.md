# 2026-10-25 출시 콘텐츠 보강

기존 카탈로그 5,728권 중 영어는 1,119권이었으나 단계·관심사 근거가 있는 영어 판본은 84권뿐이었다. 원본 권수 확대보다 실제 탐색 필터와 한국어 읽기 제안의 빈 구간을 보완했다.

- 한국어 개별 출판사 도서 22권: 감정·친구 관계·생활 습관·과학·자연. 짧은 읽기 제안과 대화/관찰 활동은 직접 작성했다.
- 영어 개별 출판사 도서 25권: 초급 리더스와 공룡·동물·과학 읽기. Step into Reading 공식 단계는 시리즈 필터 이름에 표시하되 AR로 변환하지 않았다.
- 정확한 ISBN 판본을 알라딘 Worker ItemLookUp 응답과 대조하여 제목·저자·출판사·표지를 확인했다. 기관 추천 목록이나 출판사 소개문을 복사하지 않았다.
- 47권 중 일반 카탈로그에 새로 들어간 판본46권, 기존 판본의 읽기 제안 보강1권. 전체5,774권(한국어4,630/영어1,144). 별도 읽기 제안 카드38→60권. 영어 단계 근거84→109권.

- `시간을 달리는 과학자`는 출판사 ISBN과 앱 API 응답의 정확한 판본 일치를 확인하지 못해 이번 추가에서 제외했다.
- 한국어 연령 묶음과 관심사, 영어 stage/topics는 편집 탐색 분류이며 공식 선정·추천으로 표시하지 않는다. 출판사 명시 연령은 각 evidenceNotes에 보존했다.
