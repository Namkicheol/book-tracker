## 제작 지시

캐릭터: 기존 얼굴·머리·자세·보라색 책·옷·색상과 선을 유지하며 흰 사각 배경만 실제 투명 배경으로 제거. 작은 연보라 바닥 그림자는 가장자리가 투명해지도록 유지. 새 글자나 사물 없이 정사각 구도.

카드: 세로 4:5, 따뜻한 크림색 종이와 가장자리의 옅은 분홍·라일락 수채화. 오른쪽 아래 작은 분홍 꽃과 파스텔 책 두 권. 중앙 85%는 이름과 독서 통계를 읽을 수 있도록 비워 둔다. 글자·숫자·로고·UI·인물 없이 부드러운 종이 질감.

## 동작

- 아바타 URL과 이미지 데이터는 원형 이미지로 그린다. 불러오지 못하면 책 이모지로 대체하며 원본 문자열은 그리지 않는다.
- 배경 로딩 실패 시 기존 크림·핑크 그라디언트를 사용한다.
- 저장 PNG 크기는 1080×1350이다.
