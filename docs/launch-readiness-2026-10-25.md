## 오프라인 보완 — 로컬 및 운영 검증

- `sw.js`는 자기완결형 `/offline.html`만 설치 시 필수 저장한다. 대량 자산·회원 데이터 precache는 없다.
- fallback 저장 실패 시 새 worker가 즉시 활성화되지 않도록 install 완료와 skipWaiting을 연결했다.
- activation 정리는 `momsbooks-` prefix만 대상으로 한다. 같은 origin의 다른 앱 캐시는 삭제하지 않는다.
- 오프라인에서 기존 캐시 응답이 없을 때 **navigation만** 안내 화면으로 대체한다. JSON·JS·이미지·외부 API에 HTML을 돌려주지 않는다. `/data/` 차단 유지.
- `tests/service-worker-offline.test.cjs` 4개 통과: 설치 순서/실패, namespace 정리, 방문/미방문 navigation, JSON·자산·비공개 데이터 경계.
- PR81 운영 SW/안내 페이지 바이트 일치 및 격리 WebKit 오프라인→온라인 복귀 확인. 물리적 기기의 홈 화면 설치형 재방문은 아직 남아 있다.

## 완료 판정 규칙

1. 로컬 수정, 운영 배포, 실제 사용자 동작을 별도 기록한다.
2. 새 이미지가 생성되어도 UI에서 선택되지 않거나 저장 결과가 다르면 완료가 아니다.
3. OAuth 로그인 시작 성공은 일반 사용자 가입 완료가 아니다.
4. 스토어 제출은 사용자 플랫폼 선택 및 개발자 계정·심사 정보가 확보된 뒤 해당 기준으로 관리한다.
5. 사용자 계정/서재를 점검용으로 변경하지 않는다. 합성 fixture와 실제 QA 계정 검증을 구분한다.
